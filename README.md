Add New Task: Users can create a task using a simple form.

Read All Tasks: Tasks are fetched from the backend and shown only when the "Show All Tasks" button is clicked.

Hide Task List: A "Hide Tasks" button clears the view without deleting data from the database.

Update Task : Tasks can be edited via the frontend and updated in the database.

Delete Task: Each task can be deleted individually.

Error Handling Middleware: Backend uses centralized middleware for catching and sending meaningful error responses.

MySQL Integration: All tasks are stored in a MySQL database using a structured schema.

Toast Notifications: Toast messages  inform the user when tasks are added or operations complete.
